📘 GUIDE COMPTA POUR NUL - Structure comme un PRO

1. Formule PRO : CA - (PA x Qté) = Bénéf Brut | Bénéf Brut - Loyer - Fixes - Emprunt - Bases - Com - Dép = Bénéf NET
2. Les 5 postes qui tuent bénéfice : Base (salaire fixe), Commission (% Bénéf), Loyer, Fixes (élec...), Emprunt (crédit marchandise)
3. Répartition NET : Prime % (motivation) + Patron % (ton gain) + Dev % (rachat stock) = 100%
4. Seuil rentabilité : Charges totales / jours = combien vendre/jour pour ne pas perdre. Si Emprunt 200k, seuil augmente !
